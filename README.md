# Image hosting

`images/` 폴더에 이미지를 넣고 푸시하면 아래 주소로 다른 사이트에 임베딩할 수 있습니다.

```
https://cdn.jsdelivr.net/gh/<계정>/<저장소>@main/images/<파일명>
https://raw.githubusercontent.com/<계정>/<저장소>/main/images/<파일명>
```

```html
<img src="https://cdn.jsdelivr.net/gh/<계정>/<저장소>@main/images/example.png" alt="">
```

```markdown
![](https://cdn.jsdelivr.net/gh/<계정>/<저장소>@main/images/example.png)
```
